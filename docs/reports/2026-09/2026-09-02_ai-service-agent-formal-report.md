## 문제 요약

복원된 기존 소개서는 구현 근거와 활용 사례가 풍부했지만, 임원 보고에서 먼저 필요한 고객센터 문제 규모, 사업적 차별성, 적용 경계, 의사결정 요청이 기술 설명 뒤에 배치되어 있었다. 또한 정식 보고서와 참고 자료집의 역할이 혼재되어 문서 탐색 경로가 불명확했다.

## 근본 원인

문서가 기능 개발 경위를 중심으로 성장해 왔으며, 경영 의사결정에 필요한 "왜 지금 필요한가 → 무엇을 자동화하는가 → 어떻게 안전하게 운영하는가 → 무엇을 측정하는가"의 흐름으로 재구성되지 않았다.

## 수정 내용

- `AI_SERVICE_AGENT_SERVICE_INTRODUCTION.md`를 정식 보고용 문서로 전면 재작성했다.
- 2024년 통화매니저 CS 7,047건과 자동화 우선 후보 5,436건(77.1%)을 전면에 배치했다.
- 77.1%는 실제 절감 성과가 아닌 정책·API 준비도 검증이 전제된 후보군임을 명시했다.
- MAC/비밀번호 초기화, 회선 묶음, 로그인 장애 진단의 고객 여정과 승인·이관 조건을 Mermaid 다이어그램으로 설명했다.
- 기존 AICC와 매뉴얼·OpenAPI 기반 AI 실행 모델의 차이를 비교하고, IntelliDecision, RAG/N-hop, Dynamic Tool, MCP의 관계를 정리했다.
- 테넌트 격리, 허용 메서드, 사용자 재확인, 사전 상태 저장, 감사 로그, Undo의 통제 모델을 추가했다.
- KPI, 8주 파일럿 로드맵, 도입 게이트, 역할 분담을 추가했다.
- `SELFSERVICE_AI_ASSISTANT_INTRODUCTION.md`는 참고·백업 자료집으로 유지하고 `INDEX.md`와 기존 9월 리포트의 경로·역할을 정정했다.

## v5.2 핵심 기능 소개 재구성

- 소개서 4번 장을 세 핵심 기능인 IntelliDecision, N-hop RAG, Dynamic Tool Wrapper의 대칭 구조로 전면 개편했다.
- 세 기능이 함께 동작하는 통화매니저 착신전환 시나리오를 장의 첫머리에 배치해, 탐색 질문이 실행 요청으로 전환되는 흐름을 먼저 이해하도록 구성했다.
- 각 기능에 기능 정의, 현재 시스템 활용 방식, Mermaid 흐름도, 상세 시장 사례 2개를 추가했다.
	- IntelliDecision: Anthropic Routing, Google Dialogflow CX
	- N-hop RAG: Glean, Microsoft GraphRAG
	- Dynamic Tool Wrapper: OpenAI GPT Actions, Composio
- N-hop RAG는 지식베이스 데이터 구성, 문서·도메인·화면·정책 관계, 검색부터 응답까지의 예시를 명시했다. 현재 연결된 관계와 확장 예약 관계를 구분해 과장을 방지했다.
- Dynamic Tool Wrapper는 OpenAPI 명세 기반 Tool 후보 생성과 base URL·인증·승인 정책의 필요 조건을 설명했다. "명세만으로 모든 API가 무조건 실행된다"는 식의 과장 없이, 표준 REST API에서 개별 중계 코드와 Agent Builder 작업을 줄이는 방식으로 범위를 한정했다.

## v5.3 IntelliDecision 설명 보강

- IntelliDecision을 단순 대화 유형 분류가 아니라, 유형 분류 후 사용자 목적·이전 대화·필요 정보·실행 위험도·다음 행동을 반복 판단하는 오케스트레이션 계층으로 확장해 설명했다.
- 유형 A-I별로 AI가 따라야 하는 판단 Statement, 행동 원칙, 고객 응답 예시를 추가했다.
- 착신전환 문의가 탐색에서 실행 요청과 최종 승인으로 이어지는 멀티턴 시퀀스를 추가했다.
- Anthropic Routing은 Claude와 Claude API를 제공하는 Anthropic의 에이전트 설계 패턴임을 명시하고 고객 지원에서의 활용 방식을 상세화했다.
- Google Dialogflow CX는 Google Cloud의 기업용 음성봇·챗봇 구축 서비스임을 명시하고, 콜센터 IVR·웹·모바일 채널에서 Flow/Page/Route로 대화 단계를 운영하는 방식을 상세화했다.
- 정식 소개서 전반의 구현 파일·함수명 표현을 독자가 이해할 수 있는 시스템 동작 표현으로 교체했다.
