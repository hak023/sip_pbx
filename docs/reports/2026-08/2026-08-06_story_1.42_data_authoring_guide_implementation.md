## 요약

임의의 REST-API 서비스를 우리 업로드 양식에 맞게 준비하는 방법을 안내하는 정적 페이지
`/ai-agent/knowledge-base/guide`를 신설했다. 신규 백엔드 API 없이 순수 프론트엔드 콘텐츠로
구현했다(AC5).

## 구현 내용

- OpenAPI 최소 예시(JSON)와 마크다운 Q&A 최소 예시(`{domain: xxx}` 태그 포함)를 페이지 내
  문자열 상수로 보유하고, `Blob`+`<a download>`로 즉석 다운로드 제공.
- "화면 안내(hop)가 만들어지려면" 표 — `domain_tags`, OpenAPI 엔드포인트 메타, 쓰기 승인
  (`approved_methods`)이 각각 hop 생성에 왜 필요한지 설명(코드 확인 후 작성).
- "업로드 후 자동 분류 규칙" 표 — `knowledge_base_assembler.py::classify_setting_item()`의
  실제 정규식(`_ENDPOINT_QUESTION_RE`)과 `_WRITABLE_METHODS` 판정 로직을 코드에서 직접 확인해
  사람이 읽는 표로 옮김.
- 마크다운 업로드가 실제로는 `manual_indexer.py::MarkdownManualAdapter`(Q&A 정규식 +
  `{domain: xxx}` 섹션 태그, Story 2.8)를 경유함을 코드로 확인한 뒤 예시 형식을 정확히 일치시킴.
- `/ai-agent` 지식베이스 섹션에 가이드 링크 추가.

## 검증

- `npx tsc --noEmit` / `npx eslint` 0에러.
- 신규 백엔드 로직 없음 — 백엔드 회귀 테스트 불필요.
- **실서버 IV는 미실시**(잔여 Task 5) — 가이드의 예시 파일을 실제로 업로드해 성공하는지
  dogfooding 검증이 필요.
