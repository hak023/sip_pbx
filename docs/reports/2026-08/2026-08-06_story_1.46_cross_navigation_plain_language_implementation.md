## 구현 내용

- **백엔드**: `GET /api/self-service/decision-log/sessions`에 선택적 `related_domain`/`doc_id`
  쿼리 파라미터 추가. 값이 있으면 후보 세션(최대 200개)을 각각 `get_decision_log_session_detail()`
  로 재조회해, 최소 한 턴의 RAG 매칭 결과(`matched_doc_ids`/`related_domains`)가 조건과 일치하는
  세션만 반환한다(`_session_matches_filter`, 신규 저장 로직 없이 기존 조회 경로만 재사용).
- **교차 탐색 링크**: `qa` 탭(문서 id 기준)/`catalog` 탭(도메인 기준)/`kb` 탭(문서의 첫 도메인
  태그 기준)에 "최근 이 항목이 쓰인 대화 보기" 버튼 추가 — 클릭 시 "AI 의사결정 로직" 탭으로
  이동하며 필터 배너(+"필터 해제" 버튼)와 함께 관련 세션만 로드한다.
- **hop 원시 문자열 → 카드 UI**: 공유 `HopPathTrail` 컴포넌트 신규(`humanizeHopNode`/
  `HOP_EDGE_LABEL` 매핑) — `--rendered_by(hop1)-->` 같은 원시 문자열 대신 "N단계 · {소스} ·
  이 화면에서 보여줘요 → {타깃}" 형태로 렌더링. Story 1.40 지식베이스 사례 카드와 Story 1.37
  kb 문서 hop 토글 두 곳 모두 이 컴포넌트로 통일.
- **세션 턴 자연어 요약**: `summarizeTurnPlain()` 신규 — 턴 카드 상단에 "🔍 지식 2건을 참고해
  F(모호성 해소) 방식으로 1.75초만에 답했어요" 형태의 한 줄 요약을 추가. 기존 ①~⑤ 상세 배지는
  정밀 확인용으로 그대로 유지(정보 손실 없음).
