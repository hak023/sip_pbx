## 요약

Story 1.44 응대 유형 탐색기의 매칭 미리보기 카드에서, 유형 C처럼 여러 도메인이 동시에 매칭되는
경우를 "hybrid"/"multi-domain" 같은 기술 용어 없이 도메인별로 그룹핑해 자연어로 보여주도록
보강했다. 백엔드(Story 1.33 `search_hybrid_multi_domain`)는 변경하지 않고, 프론트엔드 표시
로직만 추가한 순수 UI 작업이다.

## 구현 내용

- `frontend/lib/groupMatchedDocumentsByDomain.ts` 신규(순수 함수) — 매칭 문서를
  `related_domain` 기준으로 그룹핑, `isMultiDomain`/`domainCount` 산출.
- Story 1.44 미리보기 카드에서 `isMultiDomain=true`이면 "여러 영역(N개)을 동시에 참고했어요"
  문구와 도메인별 카드 묶음을 표시, 단일 도메인이면 기존 평평한 리스트를 그대로 유지(AC3).

## 검증

- `npx tsc --noEmit` / `npx eslint` 0에러.
- 백엔드 변경 없음(Story 1.33 로직 그대로 재사용) — 별도 백엔드 회귀 테스트 불필요.
- **실서버 IV는 미실시**(잔여 Task 4) — 유형 C 포괄 질문으로 다중 도메인 그룹핑, 단일 도메인
  질문으로 대조군 확인이 필요.
