## 요약

`settings/ai-assistant/docs` "지식 업로드" 탭 안의 `catalog`/`screen`(시스템 설정)과 `kb`(테넌트
지식 문서) 업로드 폼이 여전히 별개로 나뉘어 있던 것(Story 1.30이 UX 진입점만 통합)을, 파일 하나를
올리면 자동으로 올바른 폼에 채워지는 **단일 드롭존**으로 통합했다.

## 구현 내용

- `frontend/lib/uploadFileKind.ts`(신규, 순수 함수) — 파일 확장자·MIME·내용 시그니처로 5가지
  유형(`system_config`/`openapi`/`markdown`/`pdf`/`unknown`) 판별.
  - `system_config`: JSON 최상위에 `catalog`+`screen_graph` 키가 모두 있으면 판정.
  - `openapi`: 내용에 `openapi:`/`swagger:` 시그니처가 있으면 판정(확장자 무관, YAML도 대응).
  - 나머지는 확장자(`.pdf`/`.md`/`.txt`) 또는 텍스트 존재 여부로 폴백 판정.
- `page.tsx`에 `handleUnifiedFileDrop()`/`applyDetectedFile()`/`handleManualKindChoice()` 추가 —
  판별 결과에 따라 기존 `handleFileSelected()`(시스템 설정 import) 또는 `uploadSourceType`/
  `uploadTextBody`/`uploadFile` 상태(테넌트 지식 문서 폼)를 자동으로 채운다. 기존 API 호출·폼
  로직은 한 줄도 수정하지 않았다(NFR8 — 데이터 모델은 계속 분리, UX 라우팅 계층만 신설).
- 판별 실패(`unknown`) 시 파일을 보관해두고 4개 버튼(시스템 설정/OpenAPI/매뉴얼/PDF)으로 수동
  선택하는 폴백 UI를 제공(AC3).
