## 핵심 발견(Task 1 재확인으로 백엔드 작업 전체 생략)

착수 전 재확인 결과, "AI 의사결정 로직"(policy) 탭은 데이터 전체가 항상 `intellidecision_policy.py`
레지스트리(테넌트 무관)이고, "지식베이스 현황"(kb) 탭/업로드 문서 목록은 데이터 전체가 항상
테넌트 업로드임을 코드로 확인했다. 즉 **탭/섹션 자체가 이미 출처 구분자**이므로, AC3가 요구한
"신규 백엔드 필드 최소화"를 넘어 **아예 신규 필드가 필요 없다**고 판단해 백엔드를 전혀 수정하지
않았다.

## 구현 내용

- `frontend/app/settings/ai-assistant/docs/page.tsx`에 `OriginBadge` 공유 컴포넌트 신설
  (`kind="platform"|"tenant"`).
- 적용 위치: policy 탭 상단(플랫폼 공통), 유형별 카드의 "지식베이스 사례"(Story 1.40) 섹션
  헤더(테넌트 데이터 — 같은 탭 안에서도 실제 테넌트 업로드 데이터를 보여주므로 배지를 분리해
  붙임), kb 탭 상단(테넌트 데이터).
- `/ai-agent` 페이지의 "응대 투명성" 섹션 항목 라벨에도 "(플랫폼 공통)"/"(테넌트 데이터)" 짧은
  표기 추가(AC1의 `/ai-agent` IA 범위 충족).
