## 수행 내용

`frontend/app/settings/ai-assistant/docs/page.tsx`(신규 npm 의존성 없음, 기존 탭/폼 스타일 재사용):

1. **신규 "응답 시뮬레이터" 탭**: 예시 발화 입력 → `POST /api/knowledge-base/simulate` 호출 →
   ①매칭 지식 문서(doc_id/유사도/related_domain) ②IntelliDecision 판정(유형 코드+이름+근거 요약)
   ③실제 응답 텍스트를 3단으로 표시. 실행 버튼에 "실제 LLM 호출로 시간이 걸릴 수 있습니다"
   문구와 실행 중 로딩 상태를 표시하고, 완료 후 실측 `elapsed_sec`를 노출한다(AC4, NFR8).
2. **"AI 의사결정 로직"(policy) 탭 → 시뮬레이터 바로가기(AC5)**: 각 유형 카드의 대표 예시 발화
   옆에 "이 유형으로 시뮬레이션 →" 버튼을 추가 — 클릭 시 `simulate` 탭으로 전환하고 해당 예시
   발화로 즉시 실행한다.
3. 신규 상태(`simulateQuery`/`simulating`/`simulateResult`/`simulateError`)와 핸들러
   (`handleSimulate`/`handleSimulateFromPolicy`)만 추가 — 기존 탭 로직·API 클라이언트(`apiJson`)
   패턴을 그대로 재사용했다.
