## 핵심 발견(착수 전 재확인, 스코프 축소)

Story "AI 의사결정 로직" 탭(Story 1.32)이 이미 유형 A~I 탭 + 질문 예시 리스트 + RAG/Tool 배지를
구현해뒀음을 재확인해, 신규 `IntentExplorer` 컴포넌트를 별도로 만들지 않고 **기존 탭에 미리보기
기능만 추가**하는 방식으로 스코프를 좁혔다(Story 1.31/1.38/1.40과 동일한 "이미 된 것부터 확인"
패턴).

**중요 발견**: 원래 리포트 초안이 재사용을 제안했던 `knowledge_base_simulate.py`(Story 1.27/1.32)
엔드포인트는 실제로 `ConversationAgent.process_utterance()`를 호출해 **진짜 LLM 응답을
생성**하고 있었다 — 이를 그대로 쓰면 Story 1.39/1.40이 명시적으로 폐지한 "응답 시뮬레이터"를
그대로 재도입하는 셈이 된다. 대신 Story 1.40의 안전한 패턴(`intellidecision_manual.py`, 벡터
검색+그래프 조회만, LLM 미호출)을 임의 질문으로 확장하는 방향으로 전환했다.

## 구현 내용

- `intellidecision_manual.py::build_case_example_for_query(spec, owner, query)` 신규 — 기존
  `build_case_example_for_type()`이 `trigger_examples[0]`로 고정 호출하던 로직을 리팩터링해
  이 함수를 감싸도록 변경(기존 11개 테스트 무수정으로 통과).
- `GET /api/settings/ai-assistant/intellidecision-manual/preview?owner=&code=&query=` 신규
  엔드포인트 — 사용자가 고른 질문 예시로 실제 벡터 검색+지식 그래프 조회를 실행해 매칭 문서·
  hop 경로를 반환한다. LLM 호출 없음.
- 프론트엔드 "AI 의사결정 로직" 탭의 질문 예시 버튼을 클릭하면 곧바로 채팅으로 이동하던 것을,
  먼저 `handleExplorePreview()`가 위 API를 호출해 매칭 미리보기 카드(문서/hop 개수/"이건
  예측" 문구)를 보여주고, "이대로 실제로 물어보기" 버튼을 눌러야 기존 `handleChatFromPolicy()`
  (Story 1.39 실제 채팅 패널)로 이동하도록 변경.
