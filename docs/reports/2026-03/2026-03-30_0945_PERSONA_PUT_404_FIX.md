# Frontend Persona 404 에러 수정

**작성일**: 2026-03-30  
**상태**: 완료  
**관련 파일**: `sip-pbx/src/api/routers/persona.py`

## 문제 상황

Frontend에서 Persona 설정 시 두 가지 에러 발생:

1. **404 Not Found**: `PUT /api/persona/1004` 호출 시 발생
2. **500 Internal Server Error**: `persona_save_error: "object list can't be used in 'await' expression"`

**로그**:
```
{"timestamp": "2026-03-30T09:52:56.692", "level": "info", "event": "persona_auto_created_on_put", "name": "기상청", "owner": "1004"}
{"timestamp": "2026-03-30T09:53:01.427", "level": "error", "event": "persona_save_error", "error": "object list can't be used in 'await' expression", "owner": "1004"}
```

## 원인 분석

### 1. API 동작 방식 (404 에러)

**기존 코드** (`persona.py` Line 111-141):
```python
@router.put("/{owner}", ...)
async def update_persona(owner: str, req: UpdatePersonaRequest):
    persona = await service.get_persona(owner)
    if not persona:
        raise HTTPException(status_code=404, ...)  # ← 404 발생
```

**문제**: PUT은 **기존 Persona를 수정**하는 엔드포인트인데, ChromaDB에 해당 owner의 Persona가 없으면 404를 반환했습니다.

### 2. Embedder 함수 호출 오류 (500 에러)

**기존 코드** (`persona_service.py` Line 68):
```python
embedding = await self._embedder.embed_text(persona.description)  # ❌ 에러
```

**문제**: `embed_text()`는 **동기 함수**인데 `await`를 사용했습니다.

`embedder.py` 확인:
- `embed_text(text)`: 동기 함수 - `List[float]` 반환
- `embed(text)`: 비동기 함수 - `await asyncio.to_thread(self.embed_text, text)` 사용

**에러**: "object list can't be used in 'await' expression" - `embed_text()`가 리스트를 즉시 반환하는데 `await`를 사용하려고 해서 발생

### 2. Frontend 동작

Frontend (`sip-pbx/frontend/app/settings/persona/page.tsx`):
- **생성**: POST `/api/persona/`
- **수정**: PUT `/api/persona/{owner}`

사용자가 신규 Persona를 입력했지만, 어떤 이유로 **PUT 요청이 발생**했습니다.

가능한 시나리오:
1. 페이지 로딩 시 `loadPersonas()` 호출
2. 빈 목록이지만 편집 모드로 진입
3. "수정 저장" 버튼 클릭 → PUT 요청
4. ChromaDB에 Persona 없음 → 404

## 해결 방법

### ✅ 1. PUT 요청 시 자동 생성 (`persona.py`)

**수정된 코드** (Line 111-159):

```python
@router.put("/{owner}", response_model=PersonaResponse, summary="Persona 수정 또는 생성")
async def update_persona(owner: str, req: UpdatePersonaRequest):
    """
    Persona 수정 (부분 업데이트) 또는 생성
    
    기존 Persona가 있으면 업데이트, 없으면 자동 생성합니다.
    """
    service = get_persona_service()
    if not service:
        raise HTTPException(status_code=503, detail="PersonaService not initialized")
    
    # 기존 persona 조회
    persona = await service.get_persona(owner)
    
    if not persona:
        # Persona가 없으면 자동 생성 (name, description은 필수)
        if not req.name or not req.description:
            raise HTTPException(
                status_code=400, 
                detail="name and description are required when creating a new persona"
            )
        
        persona = OrganizationPersona(
            owner=owner,
            name=req.name,
            description=req.description,
            scope_keywords=req.scope_keywords or [],
            chitchat_response_template=req.chitchat_response_template,
            enabled=req.enabled if req.enabled is not None else True,
            created_at=datetime.now().isoformat(),
            updated_at=datetime.now().isoformat(),
        )
        logger.info("persona_auto_created_on_put", owner=owner, name=req.name)
    else:
        # 기존 persona 업데이트
        if req.name is not None:
            persona.name = req.name
        if req.description is not None:
            persona.description = req.description
        if req.scope_keywords is not None:
            persona.scope_keywords = req.scope_keywords
        if req.chitchat_response_template is not None:
            persona.chitchat_response_template = req.chitchat_response_template
        if req.enabled is not None:
            persona.enabled = req.enabled
        
        persona.updated_at = datetime.now().isoformat()
    
    success = await service.save_persona(persona)
    if not success:
        raise HTTPException(status_code=500, detail="Failed to save persona")
    
    return PersonaResponse(**persona.dict())
```

### 주요 변경 사항

#### 1. 404 제거 및 자동 생성 (`persona.py`)
- Persona가 없어도 에러를 발생시키지 않음
- `name`, `description`을 기반으로 새로 생성
- Validation: 신규 생성 시 `name`, `description` 필수 체크 (400 Bad Request)
- 로깅: 자동 생성 시 `persona_auto_created_on_put` 로그 기록

#### 2. Embedder 함수 수정 (`persona_service.py`)
- **Line 68**: `await self._embedder.embed_text()` → `await self._embedder.embed()`
- **Line 216**: `await self._embedder.embed_text()` → `await self._embedder.embed()`
- 비동기 컨텍스트에서는 `embed()` 사용 (내부적으로 `asyncio.to_thread()` 사용)

### 장점

- **사용자 친화적**: POST/PUT 구분 없이 동작
- **RESTful 표준**: PUT은 idempotent (멱등성) 지원
- **에러 감소**: 404/500 에러 해결
- **비동기 안정성**: `embed()` 사용으로 이벤트 루프 블로킹 방지
