# 도메인 설정 통합 및 시스템 템플릿 확장

**작성일**: 2026-04-09 23:50  
**상태**: 완료  
**관련 경로**:
- `sip-pbx/frontend/app/booking/page.tsx`
- `sip-pbx/frontend/app/booking/slots/page.tsx`
- `sip-pbx/frontend/app/booking/domains/page.tsx`

---

## 변경 배경

"도메인 설정" 링크가 `예약 관리`, `슬롯 관리` 두 곳의 헤더에 중복 노출되어 있어 혼란스러운 UX를 제거하고,  
슬롯 생성 시점에 바로 도메인을 추가할 수 있도록 흐름을 단순화했다.  
또한 시스템 템플릿을 다양한 업종으로 대폭 확장했다.

---

## 변경 사항

### 1. `booking/page.tsx` — "도메인 설정" 링크 제거
- 헤더의 `도메인 설정` 링크(`/booking/domains`) 제거
- 남은 메뉴: 슬롯 관리 / AI 연동 설정

### 2. `booking/slots/page.tsx` — 링크 제거 + 인라인 도메인 추가 패널
- 헤더의 `도메인 설정` 링크(`/booking/domains`) 제거
- **일괄 자동 생성 폼**과 **단일 슬롯 추가 폼** 두 곳에 `InlineDomainForm` 컴포넌트 통합
  - 도메인 드롭다운 옆에 `＋ 도메인` 버튼 추가
  - 클릭 시 해당 폼 아래에 인라인 빠른 추가 패널 슬라이드인
  - 저장 즉시 드롭다운에 자동 추가 + 해당 도메인 자동 선택
- `InlineDomainForm` 컴포넌트 특징:
  - 도메인 이름 입력
  - 프리셋 필드(이름, 전화번호, 생년월일, 인원 수, 메모) 토글 방식 선택
  - 기본값: 이름 + 전화번호 선택된 상태
  - 저장 후 자동으로 해당 도메인이 선택됨을 안내 문구 표시
- `showInlineDomain`, `inlineDomainTarget` state 추가

### 3. `booking/domains/page.tsx` — 시스템 템플릿 11 → 30개로 확장

## UX 개선 흐름

**변경 전**: 예약 목록 → 도메인 설정(별도 페이지) → 슬롯 관리 → 도메인 선택  
**변경 후**: 슬롯 관리 → 도메인 드롭다운 옆 `＋ 도메인` → 인라인 추가 → 자동 선택

도메인 설정 전용 페이지(`/booking/domains`)는 여전히 존재하며,  
복잡한 편집(필드 재정의, 선택형 옵션 추가 등)은 해당 페이지에서 수행한다.
