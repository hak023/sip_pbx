## 1. 수정 내용

1. **knowledge/ 4개 모듈**(`entity_extractor.py`, `hallucination_checker.py`, `qa_extractor.py`,
   `summarizer.py`): 지역 `import google.generativeai as genai` → `from google.genai import
   types as genai_types`, `genai.types.GenerationConfig` → `genai_types.GenerateContentConfig`.
   이 모듈들은 `self.llm.model.generate_content(...)`(Story 6.1의 `_GenAIModelAdapter`)를 이미
   경유하고 있어 저위험 변경이었다.
2. **`api/routers/call_history.py`**: `generate_unhandled_draft`가 `genai.configure()`+
   `GenerativeModel(...).generate_content_async(...)` → `genai.Client(api_key=...).aio.models
   .generate_content(model=, contents=)`로 전환.
3. **`services/ringback_service.py`**: `_call_llm`/`_call_llm_style_line` 2곳 동일 패턴 전환.
4. `self_service_agent.py`의 stale 주석(`google.generativeai.GenerativeModel` 언급) 2곳 갱신.

## 3. ⚠️ Story 범위 밖에서 발견한 기존 결함 (본 세션에서 수정하지 않음)

`ringback_service.py`가 사용하는 모델명 `"gemini-2.0-flash"`가 **이 Google 계정에서 이미
폐지(404 NOT_FOUND)** 되어 있음을 `client.aio.models.generate_content()` 패턴 검증 중 실제
API 호출로 확인했다:

```
google.genai.errors.ClientError: 404 NOT_FOUND. {'error': {'code': 404, 'message':
'This model models/gemini-2.0-flash is no longer available. ...'}}
```

- 이는 2026-07-24 세션 인계 리포트에 이미 기록된 "모델 교체 우회 시도 → `gemini-2.0-flash`
  폐지 404" 사실과 일치하며, **SDK 마이그레이션과 무관한 사전 존재 결함**이다(구 SDK로도
  동일하게 실패했을 것).
- 본 Story는 SDK 계층 치환만 범위로 하여 모델명은 변경하지 않았다 — 즉 링백 가사/스타일 자동
  생성 기능(`auto_generate_lyrics`, 스타일 라인 생성)은 **현재 실제로 항상 실패**하고 있을
  가능성이 매우 높다(단, 코드에 폴백 로직(`_FALLBACK_LYRICS`)이 있어 완전히 죽지는 않고 고정
  문구로 대체됨).
- **권장 조치**: 별도 Story/버그 리포트로 `ringback_service.py`의 모델명을
  `gemini-2.5-flash`(또는 계정에서 사용 가능한 모델)로 갱신할지 결정 필요. 이번 세션 범위
  밖이므로 수정하지 않고 보고만 한다(copilot-instructions.md "문제 은폐 금지" 원칙).
