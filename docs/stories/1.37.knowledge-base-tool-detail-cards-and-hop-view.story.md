## Story

**As a** 지식베이스 구성을 검증하려는 테넌트 관리자,
**I want** 업로드된 API(Tool)가 엔드포인트 하나하나 단위로 자세한 정보(경로/메서드/파라미터/
writable 여부)와 관련된 지식 그래프 hop 경로까지 확인 가능하기를,
**so that** "내 데이터가 어떻게 지식베이스로 구성됐는지" 투명하게 신뢰할 수 있다.

## Acceptance Criteria

1. "지식베이스" 섹션(Story 1.36 IA 재편 이후)에 API/Tool 단위 상세 카드 목록이 표시된다 — 각
   카드는 엔드포인트 경로·HTTP 메서드·writable 여부(Story 1.31 `classify_setting_item` 결과)·
   실행 승인 상태(Story 1.34/1.35, 있는 경우)를 보여준다.
2. 카드를 클릭하면 해당 API/문서와 연결된 `knowledge_graph` hop 경로(Story 1.28
   `traverse_graph()`)가 시각화된다 — 어떤 도메인·화면·IntelliDecision 유형과 연결되는지 확인
   가능해야 한다.
3. 목록/카드는 신규 API 없이 기존 `GET /knowledge-base/inventory`(Story 1.23/1.31의
   `auto_assembled.setting_items`)와 `knowledge_graph.traverse_graph()`를 조합해 구성한다(신규
   백엔드 엔드포인트가 필요하면 최소 범위로 추가).
