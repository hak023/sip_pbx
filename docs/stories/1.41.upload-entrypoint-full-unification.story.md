## Story
As a 테넌트 관리자,
I want 카탈로그 설정 파일/화면 정의/지식 문서(매뉴얼·PDF·OpenAPI)를 하나의 업로드 화면에서
파일 형식과 무관하게 올릴 수 있기를,
so that "설정 관리"와 "지식 업로드" 두 탭을 오가며 어디에 무엇을 올려야 하는지 고민하지 않아도 된다.

## Acceptance Criteria
1. `page.tsx`의 `catalog`/`screen`/`kb` 업로드 폼이 단일 드롭존 컴포넌트로 통합된다.
2. 업로드된 파일의 확장자·MIME·내용 시그니처(`openapi:`/`swagger:` 키, JSON 카탈로그 스키마
   시그니처 등)를 기준으로 자동으로 올바른 백엔드 API(`catalog-config/import`,
   `knowledge-base/documents`)로 라우팅한다.
3. 판별에 실패하면 사용자가 수동으로 유형을 선택할 수 있는 폴백 UI를 제공한다.
4. 업로드 결과(성공/실패, diff 미리보기 또는 청크 수)가 파일 유형과 무관하게 동일한 시각적
   패턴의 "업로드 결과" 패널에 표시된다.
5. 기존 `catalog-config/import`/`knowledge-base/documents` 백엔드 API와 데이터 모델은 변경하지
   않는다(NFR8 재확인, UX 레이어만 통합).
