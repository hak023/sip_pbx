> 상세 배경·설계 방향: [Epic 4 계획 리포트](../reports/2026-08/2026-08-06_epic4_platform_maturation_and_ux_transparency_planning.md) §5(FR35-E).

## Story
As a 테넌트 관리자,
I want 유형 C(포괄적 도움 요청)처럼 여러 영역을 동시에 참고하는 질문의 경우, 그 사실이 응대 유형
탐색기(Story 1.44)에서 기술 용어 없이 이해하기 쉽게 보이기를,
so that "왜 이렇게 여러 개가 한꺼번에 검색됐는지" 궁금해하지 않고 자연스럽게 이해한다.

## Acceptance Criteria
1. Story 1.44 `IntentExplorer`의 유형 C 탭에서 매칭 문서 미리보기가 도메인별로 그룹핑되어
   표시된다(백엔드 `search_hybrid_multi_domain`(Story 1.33) 결과의 `related_domain`을 그대로
   사용, 신규 백엔드 로직 불필요).
2. "hybrid"/"multi-domain" 등 기술 용어는 사용자 화면에 노출하지 않고 "여러 영역을 동시에
   참고했다"는 한국어 문구로 표시된다.
3. 단일 도메인만 매칭된 경우(하이브리드 미발동)에는 그룹핑 UI 없이 기존과 동일하게 표시된다
   (불필요한 확장 없음 — 2026-08-05 IV에서 확인된 "휴리스틱 게이팅 정상 작동" 원칙 유지).
4. 하이브리드 발동 여부는 `self_service_agent_hybrid_rag_merged` 로그와 대조 가능하도록 프론트
   화면에 도메인 수가 명확히 드러난다.
