## Story

As a 1001 테넌트 관리자, 도우미가 업로드된 OpenAPI 문서의 승인된 메서드를 실제 대화 중
Tool-calling으로 호출할 수 있기를 원한다. 그래야 QA 계획(§3 유형 B/E)이 "안내만 하는 것"이
아니라 "실제 REST-API 실행"까지 검증할 수 있다.

## Acceptance Criteria

1. `self_service_agent.py`의 Tool-calling 루프(`_try_bind_self_service_tools`/Gemini native FC
   경로)가 `SELF_SERVICE_TOOLS`뿐 아니라, 현재 owner에 대해 승인된
   `knowledge_document`(source_type=openapi) 메서드도 동적으로 Tool 목록에 포함한다.
2. 승인되지 않은 메서드는 Tool 목록에 노출되지 않는다(화이트리스트 원칙 유지, Epic 2/3 원칙
   재사용).
3. 실행 결과는 `tool_execution_log`(Story 1.34)에 기록되고, 기존 `self_service_decision_log`
   세션 순서도(Story 1.38)에서도 조회 가능해야 한다.
4. Undo(유형 E) 요청 시 `dynamic_api_tool.py::undo_last_execution()`이 실제로 호출되는 경로가
   확인되어야 한다(§5 갭 C).
5. 기존 `SELF_SERVICE_TOOLS` 기반 흐름(설정 카탈로그 변경)은 회귀 없이 그대로 동작해야 한다.

## Dev Agent Record

- **구현 요약**: `dynamic_api_tool.py`에 `build_dynamic_tools_for_owner(owner)` 신설 — owner의
  `knowledge_documents`(source_type=openapi) + `knowledge_document_endpoints`를 조회해, GET은 항상
  포함하고 쓰기 메서드는 `approved_methods`에 있는 것만 LangChain Tool로 노출한다(미승인
  메서드는 Tool 목록에서는 아예 제외되어 LLM이 보지 못함, NFR9 화이트리스트 원칙 유지). 각
  Tool은 `execute_api_endpoint()`를 호출하며, 경로 파라미터(`{order_id}` 등)는 `params` dict에서
  자동 추출해 URL에 치환한다. 문서가 없으면 이전과 동일하게 빈 리스트를 반환해 기존
  `SELF_SERVICE_TOOLS` 흐름에 영향 없다.
- **Undo 연결**: 사용자가 "방금 한 거 취소해줘"라고 말할 때 document_id를 모르므로,
  `find_last_undoable_document_id(owner)`로 owner의 문서 전체를 대상으로 최근 되돌리지 않은 쓰기 이력을
  찾은 뒤 기존 `undo_last_execution()`을 호출하는 제네릭 Tool(`_undo_last_dynamic_api_change`)을
  추가했다(owner에 openapi 문서가 1개 이상일 때만 노출).
- **연결 지점**: `self_service_agent.py`에 `_self_service_tools_for_owner(owner)` 신설
  헬퍼를 두고, `_try_bind_self_service_tools`/`_try_build_self_service_gemini_fc`/
  `_execute_self_service_tool` 세 함수 모두 이 헬퍼로 SELF_SERVICE_TOOLS+동적 Tool을 합친 목록을
  사용하도록 수정(시그니쳐에 `owner` 파라미터 추가). 기존 보안 원칙(owner 강제 치환, tool_args["owner"]
  강제 설정)은 모든 Tool에 동일하게 적용된다(Tool 종류 구분 없이 적용되는 기존 코드에 변경 없음).
- **테스트**: 신규 `TestBuildDynamicToolsForOwner`(4건) + `TestFindLastUndoableDocumentId`(2건),
  기존 `test_self_service_settings_tool.py`의 owner 파라미터 추가된 함수 시그니처에 맞춰 fake 함수들
  갱신. `tests_new/unit -k "self_service or dynamic_api or intellidecision"` 259건 전체 통과(0 FAILED).
- **의도적 미구현(후속)**: 동적 Tool 목록은 턴 및 도구 실행 마다 DB 조회로 다시 생성한다(캠싱 없음) —
  문서 수가 적은 QA 규모에서는 문제없으나, 대규모 테넌트/문서에서는 성능 최적화(owner+문서
  버전 기준 캐싱)가 필요할 수 있음.
