## Story

**As a** "뭘 도와줄 수 있는지" 포괄적으로 묻는 사용자를 상대하는 AI 도우미,
**I want** 여러 도메인/문서 유형에 걸쳐 검색한 결과를 카테고리별로 요약해 종합적으로 답하고,
**so that** 특정 도메인 하나로 좁혀지지 않는 질문에도 지식베이스 전체를 대표하는 답을 줄 수 있다.

## Acceptance Criteria

1. `intellidecision_policy.py`에 신규 `rag_strategy_hint` 값 `hybrid_multi_domain`이 추가되고
   유형 C에 적용된다.
2. 유형 C 판정 시 검색 로직이 단일 컬렉션/단일 도메인이 아니라 **여러 도메인(또는 여러 문서
   유형)에 걸쳐 병렬 검색** 후 카테고리별로 집계해 응답에 반영한다(GraphRAG Global Search의
   "여러 커뮤니티 요약을 종합"하는 개념을 경량 버전으로 적용, 리서치 §3.11 근거).
3. Story 1.32 시뮬레이터에서 유형 C 질문을 선택하면 hop 시각화가 "여러 소스가 병렬로 매칭되어
   종합됐다"는 것을 다른 유형(단일 hop 체인)과 다르게 표시한다(예: 병렬 브랜치 시각화).
4. 기존 유형 C 응대(Story 1.15, "3개 카테고리 요약 + 마무리 문구")의 실제 응답 품질은 이번
   변경으로 저하되어서는 안 된다(회귀 확인 필수, 베이스라인 대비 A/B).
5. NFR1(지연 예산) 보호 — 다중 도메인 병렬 검색이 추가 지연을 유발하지 않도록 `asyncio.gather`
   등으로 병렬화해야 한다(순차 검색 금지).
