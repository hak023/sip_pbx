# Story 8.2 — MCP 게이트웨이 쓰기 Tool + Undo Tool 노출

## Status
Draft

## Story
승인된 POST/PUT/DELETE 엔드포인트와 Undo Tool이 MCP 클라이언트에 노출되어  
자연어로 외부 REST-API의 상태를 변경하고, 필요 시 되돌릴 수 있다.

## Acceptance Criteria
- AC1: `approved_methods`에 포함된 메서드만 Tool로 노출된다(미승인은 Tool 목록에 아예 없음)
- AC2: 쓰기 Tool 호출 시 GET 스냅샷 → 실행 → `tool_execution_log` 기록 흐름이 동일하게 작동한다
- AC3: `_undo_last_dynamic_api_change` Tool이 노출되고 실제 역호출이 성공한다
- AC4: 승인되지 않은 메서드 Tool을 직접 이름으로 호출하려 해도 서버가 Tool 목록에 없으므로 실행 자체가 불가하다
