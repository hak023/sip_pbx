## Story

**As a** 셀프서비스 AI 도우미를 운영하는 테넌트 관리자,
**I want** "지식 업로드"와 "설정 관리"로 나뉘어 있던 업로드 화면을 하나의 진입점에서 이용하고,
**so that** "테넌트 지식(매뉴얼/PDF/OpenAPI)"과 "시스템 공통 설정/구성(카탈로그·화면 안내)"을 헷갈리지 않고 한 화면에서 구분해 다룰 수 있다.

## Acceptance Criteria

1. `settings/ai-assistant/docs` 최상위 탭에서 "지식 업로드"와 "설정 관리"가 하나의 "지식 업로드" 탭으로 통합된다(최상위 탭 개수 1개 감소).
2. 통합된 탭 내부에 소스 유형 선택 UI(예: 세그먼트 컨트롤/서브탭)가 있어 "① 테넌트 지식 문서"(Story 1.26 기존 업로드 폼·목록 그대로 재사용)와 "② 시스템 공통 설정/구성"(Epic 2 Story 2.4/2.5 export/import/버전 이력 그대로 재사용)을 전환해 볼 수 있다.
3. "② 시스템 공통 설정/구성" 섹션에는 FR33-C에 따라 "시스템 표준(테넌트 무관 고정)" 배지가 표시되고, 어떤 항목이 테넌트별로 커스터마이즈 가능한지/불가능한지 명확히 구분 표시된다(예: `intellidecision_policy` 유형 정의는 표준·읽기 전용, `catalog_config`/`screen_graph`는 테넌트가 편집 가능).
4. 기존 API 엔드포인트(`/api/knowledge-base/documents`, `/catalog-config/*`)는 변경하지 않는다(순수 프론트엔드 UX 재편, CR 원칙 — 회귀 위험 최소화).
5. 기존 두 탭 각각의 단위 동작(업로드/조회/수정/삭제, export/import/activate/rollback)은 재배치 후에도 100% 동일하게 동작해야 한다(Integration Verification).
