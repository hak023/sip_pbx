## Story
As a 테넌트 관리자,
I want `/settings/ai-assistant/docs`의 매뉴얼 Q&A/설정 카탈로그/화면 안내 항목을 하나의 목록에서
한 번에 훑어보기를,
so that 무엇을 확인하려고 매번 다른 탭을 오갈 필요 없이 내 AI 도우미가 아는 지식 전체를 파악할 수 있다.

## Acceptance Criteria
1. `qa`(매뉴얼 Q&A)/`catalog`(설정 카탈로그)/`screen`(화면 안내) 3개 배열이 유형 배지(문서/설정/
   화면안내)가 붙은 단일 리스트로 병합되어 표시된다.
2. 각 리스트 행에는 제목과 도메인 태그만 표시하고, raw JSON이나 내부 ID 같은 원시 필드는
   기본적으로 노출하지 않는다.
3. 리스트 상단에 유형 필터(전체/문서/설정/화면안내)와 텍스트 검색 박스가 있다.
4. `policy` 탭(의도 유형/수동 케이스/의사결정 세션)은 이번 통합 리스트에 포함하지 않고 기존
   탭 위치에 그대로 유지된다.
5. 기존 `loadQa`/`loadCatalog`/`loadScreens` 데이터 로딩 훅과 API 호출은 변경하지 않는다(신규
   컴포넌트는 이미 로드된 배열을 병합해 표시하는 프리젠테이션 레이어만 추가).
6. `npx tsc --noEmit`, `npx eslint` 0 에러.

### 2026-08-06 후속 수정 — qa 항목이 같은 제목으로 중복 나열되던 문제

사용자 검증 결과 "같은 제목(예: 'AI 에스컬레이션 설정')이 3번 반복돼 보인다"는 문제가
확인됐다. **근본 원인**: `items`(qa) 배열은 매뉴얼 문서의 개별 청크(질문 1개당 1행) 단위이며,
같은 섹션(`section_title`)에 속한 여러 청크가 각각 별도 행으로 매핑되어 실제로는 다른
질문/답변인데도 리스트에는 `it.section_title`(있으면 이를 title로 사용)만 보여 동일 제목이
반복되는 것처럼 보였다.

**수정**: `buildUnifiedKnowledgeItems()`가 qa 항목을 `section_title` 기준으로 그룹핑해
섹션당 리스트 행 1개만 생성하도록 변경(`QaGroup` 타입 신설, `entries`에 원본 청크 전체 보존).
상세 패널(Story 1.49)에서 그룹 내 모든 질문/답변을 나열해 정보 손실은 없다. 리스트 항목
UI도 배지/제목/도메인 태그를 세로로 나눠 가독성을 높이고, 도메인 태그에 `DOMAIN_LABEL`
한글 라벨을 적용(기존에는 원시 도메인 코드만 노출).

`npx tsc --noEmit` 재검증 0에러.
