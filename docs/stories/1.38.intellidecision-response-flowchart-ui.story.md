## Story

**As a** AI 도우미의 응대 로직을 검증하려는 테넌트 관리자,
**I want** 유형별 응대 과정(유형 판정 → RAG 검색 → hop 확장 → 화면안내/Tool 판단 → 응답 생성)이
순서도(flowchart) 형태로 시각화되기를,
**so that** 각 단계에서 지식베이스가 어떻게 활용되는지 직관적으로 이해할 수 있다.

## Acceptance Criteria

1. "응대 투명성" 섹션(Story 1.36 IA 재편 이후)에 유형별 응대 흐름을 나타내는 flowchart UI가
   추가된다 — 단계: ①유형 판정(A~I) ②RAG vector 검색 ③`knowledge_graph.traverse_graph()` hop
   확장 ④화면안내/Tool 필요 여부 판단 ⑤응답 생성.
2. 각 단계 노드를 클릭하면 해당 단계의 실제 데이터(정책 메타데이터, hop_path 등)가 인라인으로
   펼쳐진다.
3. RAG vector 검색 결과와 관련 hop이 어떻게 활용됐는지, 화면안내 hop이 어떻게 활용됐는지 각각
   별도 색상/구간으로 구분해 표시한다(사용자 요청 3-2 반영).
4. 유형 C(하이브리드 다중 도메인)는 다른 유형과 다른 병렬 분기 형태로 표시된다(Story 1.33 AC3
   계승).
