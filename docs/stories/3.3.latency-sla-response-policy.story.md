## Status

## Story

**As a** 발신자(고객),
**I want** AI 응답이 오래 걸릴 때 침묵 대신 적절한 안내를 받고 싶다,
**so that** 전화가 끊겼다고 오인하거나 불필요하게 재질문하지 않는다.

## Acceptance Criteria

1. Story 3.2의 `response_latency_sla_exceeded` 이벤트 발생 빈도/원인 분포 데이터를 최소 1~2주(또는
   QA 샘플 수십 건) 수집한다.
2. 수집 데이터를 근거로 정책(예: "N초 초과 시 대기 멘트 삽입" 또는 "즉시 HITL 폴백")을 결정하고
   사용자/PO 승인을 받는다(Open Question 1, PRD 승인 전 확정 필요 항목).
3. 승인된 정책이 코드로 반영되고, 정책 발동 여부가 `call_data_record`에 로깅된다.
4. 정책 발동이 정상 케이스(5초 이내)의 응답 흐름에는 영향을 주지 않는다.
