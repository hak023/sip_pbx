# Story 1.42: 데이터 작성 가이드 문서 페이지

## Status
Review

> 상세 배경·설계 방향: [Epic 4 계획 리포트](../reports/2026-08/2026-08-06_epic4_platform_maturation_and_ux_transparency_planning.md) §5(FR35-B).

## Story
As a 테넌트 관리자(또는 신규 도메인 통합 담당자),
I want 우리 시스템이 아닌 임의의 REST-API 서비스를 업로드용 데이터로 만드는 방법을 안내받기를,
so that 개발자 도움 없이도 API 문서·매뉴얼을 우리 양식에 맞게 준비해 업로드할 수 있다.

## Acceptance Criteria
1. `/ai-agent/knowledge-base/guide`(가칭) 신규 페이지가 "AI 에이전트" IA(Story 1.36) 지식베이스
   섹션에서 링크로 노출된다.
2. 지원 파일 형식(OpenAPI 3.x 스펙, Markdown Q&A 섹션 태그 형식 `{domain: xxx}`(Story 2.8),
   PDF) 각각의 최소 예시 파일을 다운로드할 수 있다.
3. "화면 안내(hop)"가 생성되려면 어떤 메타데이터가 필요한지(Story 1.28 그래프 노드 요구사항)를
   표로 설명한다.
4. 업로드 후 자동 분류 규칙(Story 1.31 `classify_setting_item()` — HTTP 메서드 기반 writable
   추정, 질문 포맷 정규식 매칭)을 사람이 읽는 표로 설명한다.
5. 순수 정적 콘텐츠 페이지로 구현하며 신규 백엔드 API는 만들지 않는다(예시 파일은 프론트엔드
   정적 자산으로 제공).
