## Story

**As a** 테넌트 관리자,
**I want** 내 번호로 AI와 대화했을 때 AI가 어떤 판단을 내렸는지 화면에서 직접 확인하기를,
**so that** AI 응대를 신뢰하고, 예상과 다른 응대가 있었을 때 그 이유를 스스로 파악할 수 있다.

## Acceptance Criteria

1. `settings/ai-assistant/docs` 페이지의 기존 "AI 의사결정 로직" 탭(Story 1.18 축 C-1)에 하위
   섹션 또는 신규 탭으로 **"최근 판단 이력"** 이 추가된다.
2. 최근 판단 이력은 `GET /api/self-service/decision-log`를 호출해 시각·유형(A~I 코드+한글명,
   `intellidecision-policy` API의 기존 유형 메타데이터와 조인해 표시)·근거 요약·관련 도메인/화면을
   표 형태로 표시한다.
3. 데이터가 없을 때(아직 판단 이력 없음)는 빈 상태 메시지를 표시하고 에러를 던지지 않는다.
4. 원본 발화 전문은 화면에 표시하지 않는다(Story 1.21 AC3-1과 일관, 근거 요약만 표시).
5. 신규 npm 의존성을 추가하지 않는다(Story 1.18 축 C-1의 기존 카드/표 컴포넌트 패턴 재사용).
6. `npx tsc --noEmit`/`npx eslint` 정적 검증을 통과한다.
