## Story
As a 테넌트 관리자,
I want 지식 문서를 업로드하고 나면 방금 등록된 항목이 바로 강조되어 보이기를,
so that 업로드가 성공했는지, 그리고 그 데이터가 어떻게 인식됐는지를 별도로 찾아보지 않고 바로 확인할 수 있다.

## Acceptance Criteria
1. `upload` 탭에서 문서 업로드가 성공하면, 통합 리스트(Story 1.48)에서 방금 등록된 항목이
   자동으로 선택되고 상세 패널(Story 1.49)에 강조 표시된다.
2. 업로드 성공 직후 사용자가 별도로 탭을 이동하거나 목록에서 항목을 찾지 않아도 상세 정보가
   바로 보인다.
3. 기존 `handleUploadDocument`의 업로드 요청/에러 처리 로직은 변경하지 않는다 — 성공 콜백에
   신규 항목 선택 로직만 추가한다.
4. `npx tsc --noEmit`, `npx eslint` 0 에러.
