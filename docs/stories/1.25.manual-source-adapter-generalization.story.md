## Story

**As a** 셀프서비스 AI 도우미의 지식베이스를 확장하려는 개발자,
**I want** 마크다운 매뉴얼 외의 소스(API 스펙, Tool docstring 등)도 어댑터 추가만으로 색인할 수
있고,
**so that** 향후 새로운 유형의 문서가 늘어나도 `manual_indexer.py` 자체를 매번 고치지 않고
확장할 수 있다.

## Acceptance Criteria (초안, 구현 착수 전 스파이크로 재검증 필요)

1. `manual_indexer.py`의 마크다운 파싱 로직(`_SECTION_PATTERN`/`parse_manual_qa_with_meta` 등)이
   `SourceAdapter` 인터페이스(가칭, `parse(raw_text) -> list[dict]`)로 감싸지고, 기존 마크다운
   파서는 이 인터페이스의 첫 번째 구현체(`MarkdownManualAdapter`)로 이관된다.
2. 기존 `index_self_service_manual()` 호출부(`settings_ai_assistant.py` 등)는 시그니처·동작이
   변경되지 않는다(순수 내부 리팩터링, 회귀 없음).
3. 기존 매뉴얼 Q&A 52건(§9 포함)의 색인 결과가 리팩터링 전후 **1바이트도 다르지 않아야 한다**
   (Story 2.3의 "정적 레지스트리 → DB 우선" 전환 시 사용한 직접 비교 검증 패턴 재사용).
4. Contextual Retrieval(청크별 LLM 자동 맥락 요약) 적용 여부는 이번 Story 범위에서 **채택하지
   않는다** — 별도 스파이크(청크 품질·색인 비용·지연 실측)로 먼저 검증 후 후속 Story에서 결정한다
   (Story 1.20의 "스파이크 우선" 관례 재사용).
5. 신규 소스 어댑터(예: OpenAPI 스펙 파서)의 구체적 구현은 이번 Story 범위에 포함하지 않는다
   (인터페이스 도입 + 기존 마크다운 어댑터 이관까지만). 실제 신규 소스 유형 추가는 수요가
   확인된 후 별도 Story로 진행한다.

## Dev Notes

- **왜 이번 Story는 Draft로만 남기고 바로 구현하지 않는가**: Story 1.23/1.24와 달리 이 Story는
  기존 색인 파이프라인의 핵심 로직(`manual_indexer.py`)을 리팩터링하는 작업이라, 우선순위 1/2
  (지식베이스 인벤토리 투명성/RAG 매칭 정책 메타데이터)보다 범위가 크고 회귀 위험이 상대적으로
  높다(PRD FR31 우선순위 ①이 가장 마지막인 이유와 동일). 착수 전 반드시 Task 1의 설계 스파이크로
  인터페이스 경계를 먼저 확정해야 한다.
- **Contextual Retrieval을 이번 Story에 포함하지 않는 이유**: 리서치(§1.2)가 제시한 실증 효과는
  대규모 지식베이스(수천~수백만 청크) 기준이며, 우리 매뉴얼은 52건 규모라 효과가 제한적일 수
  있다. 청크당 LLM 호출이 추가되는 색인 비용·지연도 실측 없이 채택하지 않는다(성급한 최적화 방지
  원칙, `coding-standards.md`와 일관).
- **회귀 검증 방법론**: Story 2.3(Screen Graph 정적→DB 전환)이 사용한 "리팩터링 전후 결과를
  스크립트로 직접 바이트 단위 비교" 패턴을 그대로 재사용할 것 — 이 저장소에서 이미 검증된
  가장 안전한 리팩터링 검증 방식이다.

  파라미터로 주입받도록 하는 것이 회귀 위험이 가장 낮은 경계로 판단(기존 함수

- `MarkdownManualAdapter.load_pairs()`/`load_pairs_with_meta()`는 기존 모듈 레벨 함수
  `load_manual_qa_pairs()`/`load_manual_qa_with_meta()`를 그대로 호출한다(새 로직 없음) —
  기존 테스트가 모듈 수준 `load_manual_qa_pairs`를 `monkeypatch.setattr`하던 것도 그대로
  유효함(파이썬 전역 네임스페이스 끔어쓰기 특성상 메서드 바디 안의 호출도 패치가 반영됨).
- `index_self_service_manual()`은 `adapter or _DEFAULT_ADAPTER`로 기본값을 채워 기존 호출부
  (`settings_ai_assistant.py` 2곳)가 전혀 무수정이다(AC2).
