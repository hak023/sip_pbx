# 레퍼런스 추적표 — 핵심 모듈 ↔ 근거 레퍼런스 ↔ 채택/변형/기각 사유

**작성일**: 2026-08-06
**상태**: 완료(Story 1.47, FR35-H)
**목적**: 기존 리서치 문서들은 "조사 시점에 무엇을 발견했는가"의 기록이지, "우리 코드의 어느
부분이 어느 레퍼런스를 근거로 그렇게 설계됐는가"를 모듈 단위로 역참조하지 않는다. 이 문서는
그 역참조 인덱스이며, 향후 유저 친화적 프로젝트 소개 문서("이 로직은 이 연구를 참고해 신뢰성을
높였다") 작성 시 1차 소스로 쓰기 위해 만들었다.

> **범위 안내**: 이 문서는 신규 리서치가 아니라 **기존에 이미 수행된 리서치의 인용 근거를
> 모듈별로 재정리한 인덱스**다. 상세 원문 인용·번역·실사용 사례는 아래 표에 링크된 원본 리서치
> 문서에 그대로 남아 있으며, 여기서는 요약과 링크만 제공한다(중복 작성 방지).
